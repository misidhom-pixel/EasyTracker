# EasyTracker

تطبيق ويب واحد فيه:
- **مولد أكواد التفعيل** (مع خاصية مسح رقم الجهاز بالكاميرا)
- **سجل تتبع الأجهزة** (شركات، أجهزة، تواريخ اشتراك، نسخ احتياطي/استيراد)

البيانات بتتخزن محليًا على المتصفح نفسه (`localStorage`) — مفيش سيرفر أو قاعدة بيانات خارجية.

## محتويات المشروع

```
├── index.html      ← التطبيق نفسه (كل الصفحات والمنطق جواه)
├── manifest.json   ← بيانات التطبيق كـ PWA (الاسم، الأيقونات، الألوان)
├── sw.js           ← Service Worker لتشغيل التطبيق أوفلاين وتثبيته كتطبيق
├── package.json    ← لتشغيل سيرفر محلي بسيط أثناء التطوير
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    └── icon-512-maskable.png
```

## 1) رفعه على GitHub

```bash
git init
git add .
git commit -m "EasyTracker PWA"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

## 2) استضافته مجانًا بـ GitHub Pages

1. من صفحة الريبو على GitHub: **Settings → Pages**
2. تحت **Build and deployment** اختار **Deploy from a branch**
3. اختار الفرع `main` والمجلد `/ (root)` واضغط **Save**
4. بعد شوية هيديك رابط شكله:
   `https://<username>.github.io/<repo>/`

> **مهم:** Service Worker (وبالتالي التثبيت والعمل أوفلاين) مش بيشتغل إلا على `https://` أو `localhost` — GitHub Pages بيوفر HTTPS تلقائي، فمفيش حاجة زيادة تعملها.

## 3) تشغيله محليًا وقت التطوير

```bash
npm install
npm start
```

هيفتح على `http://localhost:5500`. فتح `index.html` مباشرة كملف (`file://`) قد يمنع بعض المتصفحات من السماح بالكاميرا أو الـ Service Worker، فالأفضل دايمًا سيرفر محلي أو GitHub Pages.

## 4) تثبيت التطبيق على الجهاز (زي أي تطبيق)

**على الكمبيوتر (Chrome / Edge):**
افتح رابط GitHub Pages، هتلاقي أيقونة تثبيت (⊕) في شريط العنوان، أو زرار **"تثبيت التطبيق على الجهاز"** في الشاشة الرئيسية داخل التطبيق نفسه. اضغط عليها → التطبيق هيتفتح في نافذة خاصة بيه في قائمة البرامج.

**على أندرويد (Chrome):**
افتح الرابط → قائمة المتصفح (⋮) → **"إضافة إلى الشاشة الرئيسية" / Install app**.

**على iPhone/iPad (Safari):**
افتح الرابط → زرار المشاركة (Share) → **"إضافة إلى الشاشة الرئيسية" / Add to Home Screen**.
(سفاري ما بيدعمش زرار التثبيت التلقائي، فلازم الخطوة دي يدويًا.)

## ملاحظات

- خاصية مسح رقم الجهاز بالكاميرا محتاجة إنترنت أول مرة بس (لتحميل مكتبة قراءة النص Tesseract.js)، وبعدين بتتخزن في الكاش.
- لو غيّرت أي حاجة في `index.html` بعد النشر، غيّر رقم النسخة `CACHE_VERSION` في `sw.js` عشان المستخدمين ياخدوا آخر تحديث بدل النسخة المخزنة في الكاش.
